> 更新：2026-09-14。依据：本轮A—D阶段定稿与后续用户澄清。

## 1. 功能全景

以下分组表示职责与能力，不等于一级导航，也不要求每行独立建设一个页面。来源：[A：资料与练习](discussions/A-personal-profile-and-preparation.md)、[B：机会与投递](discussions/B-opportunities-and-applications.md)、[C：进程与考核](discussions/C-selection-and-interview.md)、[D：Offer与结束](discussions/D-offers-and-closing.md)。

| 编号 | 功能分组 | 已确认的操作与结果 | 入口、归属与复用 | 来源 |
|---|---|---|---|---|
| F01 | 个人资料 | 自选填写个人信息、优势、教育、工作/实习、项目、证书、社团、志愿经历及技能；允许空缺 | 个人资料页面；跨岗位共享的事实基础 | A |
| F02 | 求职意向 | 维护期望职位、行业、城市、薪资等，支持多个意向 | 与个人资料共同维护，供推荐与个性化工作读取 | A |
| F03 | 简历与附件 | 导入简历整理资料，编辑、预览、导出并保存附件 | 个人资料与岗位工作台复用能力；个人附件与岗位材料分别归属 | A、B |
| F04 | 润色与检查 | 输入框AI润色、按需检查、ATS检查与评分；用户决定是否采用 | 个人资料和岗位简历共用；发现档案事实冲突时提醒用户决定 | A、B |
| F05 | 自由练习 | 选择知识、经历或自定主题，学习、问答、追问、模拟面试，保存反馈与笔记并继续练习 | 个人练习场随时使用，无需岗位或邀请；记录属于自由练习 | A、C |
| F06 | 岗位专项准备 | 结合当前JD、岗位简历及已知轮次要求，复习基础知识、讲述经历、开展专项练习或模拟 | 岗位工作台创建后即可使用；练习场和工作台打开同一界面与记录 | A、B、C |
| F07 | 练习内容供给 | 常用职业精选内容、跨职业主题、个人资料补充及按需生成；维护来源、分类、解析和评价要点 | 共享内容用于自由练习与岗位准备；生成内容与已审核内容区分 | A、C |
| F08 | 公司招聘目录 | 浏览、筛选公司、领域、招聘类型、批次、人群、地点及岗位方向摘要，进入官方招聘入口 | 公共目录；后端每日维护；不全量复制企业岗位列表 | B |
| F09 | 机会分析 | 按用户需求推荐公司，或访问官网搜索具体岗位、读取JD、分析匹配点与优先级；保存列表或导出Excel | 分析结果保留来源、读取时间与实际检索范围 | B |
| F10 | 岗位建档 | 选定岗位并准备投递时创建卡片和工作台，保存JD、官方链接及所用内容 | 单岗位持续工作空间，贯穿材料、网申、考核与录用 | B |
| F11 | 岗位简历 | 按JD选择经历、优化表达、检查、预览并导出岗位简历 | 保存在当前岗位，不自动覆盖个人资料；与网申共享 | B |
| F12 | 网申辅助 | 内置浏览器读取表单、利用原网站简历解析、补填与检查格式和遗漏，交给用户检查，核验实际提交结果 | 当前岗位JD＋个人资料＋岗位简历；材料编辑与网页填写可往返 | B |
| F13 | 通知识别 | 读取邮件和页面结果，识别岗位、阶段、轮次、时间与待办；按实际链接处理确认事项 | 自动跟踪邮箱；短信、电话及线下事实由用户补记 | C |
| F14 | 动态进程 | 按各岗位已获知的阶段与状态逐步渲染，用户可手动更新；明确的下一轮通知可更新上一轮通过 | 卡片、工作台、时间线使用同一进程；不预设未来节点，不靠时间流逝认定完成 | C及后续澄清 |
| F15 | 日程与提醒 | 将有明确时间的考核和交接事项同步到日程，记录确认、改期等实际状态并提供主动提醒 | 与岗位进程、Offer交接共用；重复通知不重复创建同一事件 | C、D |
| F16 | 考核复盘 | 按实际场次整理问题、回答、反馈和改进行动，薄弱内容可继续发起该岗位练习 | 练习场和岗位工作台访问同一份复盘；模拟反馈仍属于练习记录 | C |
| F17 | Offer池 | 集中展示录用意向及正式Offer，维护条件、期限与依据 | 独立入口关联原岗位；收到、接受、入职分别表达 | D |
| F18 | Offer比较 | 选择多个Offer，并排比较工作、地点、薪酬、福利、成长和个人考虑；Agent补充公开背景与分析 | 私有条件由用户或录用材料提供；只加载所选Offer比较资料与相关个人偏好 | D |
| F19 | 材料交接 | 从实际要求整理事项、材料、接收方、入口、期限、办理状态与结果，辅助准备和核对 | 每个Offer关联原岗位；复用工作台、邮件和日程；提交不等于对方审核通过 | D |
| F20 | 实习转正衔接 | 实际收到转正考核时使用考核流程，收到转正意向或Offer时使用录用流程 | 复用已有能力，转正条件与原实习录用条件分开记录 | D |
| F21 | 结束本轮求职 | 用户主动结束，停止本轮主动跟踪、任务推进与提醒，保留资料与历史，呈现恭喜或祝福动画 | 全局操作，任何阶段可用；不停止公共目录维护，不改写外部招聘事实 | D |

## 2. 跨模块的一致规则

| 规则 | 功能之间如何协作 |
|---|---|
| UI与Agent能力同源 | 资料维护、材料编辑、进程更新等使用同一套产品能力，结果保存在同一份业务记录中，用户直接操作与Agent操作可以接续 |
| 入口与功能分开 | 个人练习场和岗位工作台可以打开同一条练习或复盘；更换入口不复制成果，主动开始新练习才创建新记录 |
| 练习可用性与招聘阶段分开 | 自由练习随时进行；有岗位工作台即可岗位准备；考核复盘关联现实中参加过的场次 |
| 内容与上下文分开 | Python等基础知识可以用于任何相关岗位准备，职业知识共享；岗位问答、简历和复盘不会因此跨岗位加载 |
| 岗位进程逐步获知 | A已知投递、笔试、一面，就只展示这些节点；B已知投递、一面、二面、HR面，就展示B的这些节点。新信息到达再更新，不预画统一全流程 |
| 个人基础与岗位材料分开 | 个人资料共享；JD、优化简历、网申内容与岗位成果属于具体岗位。切换岗位时同时切换Agent上下文 |
| 跨岗位分析有明确范围 | 机会分析读取本次检索资料；Offer比较读取用户所选对象。分析结果不自动注入每个岗位工作台 |
| 状态有事实依据 | 邀请、完成、通过分别记录；时间过去、填写完成、上传成功分别不等于考核完成、申请已提交、交接已通过 |

## 4. 2026-09-14确认纳入的补充能力

六类补充能力的整合方式均已确认，三层整合方式及未来插件市场也已确认。现场能力限定为记录与复盘支持，不提供作弊或AI作答提示。本节扩展A—D的能力范围，已有资料归属、岗位隔离与动态进程规则继续适用。完成的是能力范围、归属及主要协作方式的整合，具体页面交互与技术实现尚未完成设计。

| 补充方向 | 已确认纳入的能力范围 | 与已有范围的关系 |
|---|---|---|
| 简历制作细节 | 自有编辑器提供资料选取、模板排版、局部润色、修改对照、版本管理、预览与导出 | 个人基础简历与岗位版本共用编辑能力；求职信复用材料编辑能力 |
| 机会/岗位收藏 | 公司与具体岗位均可收藏，保存来源与备注；具体岗位按需保存JD | 用户开始办理时创建或关联工作台并沿用收藏资料；收藏不等于已经投递 |
| 练习方式 | 统一空间支持文字、语音、外语，以及编程、案例分析、作品讲解等场景；按内容展示代码或材料区 | 扩展F05—F07，不改变自由练习与岗位准备的入口、上下文和记录归属 |
| 准备内容组织 | 用户主动请求时，根据目标、个人资料、当前岗位JD及已知要求或复盘薄弱项，整理可选的准备主题；用户可删除、补充并直接进入练习 | 练习之前或两次练习之间使用；自由练习、岗位准备和复盘后续练习共用，不另建独立模块，不强制生成或完成计划 |
| 真实面试记录 | 允许与现场记录相关的能力，包括记录、转写及与事后复盘衔接；不提供AI知识回答、答题建议或其他作弊能力 | 关联实际岗位与场次；记录实际发生的内容，不能补造回答；具体记录媒介与界面另行设计 |
| 其他扩展 | 求职信复用材料编辑；谈薪进入练习场并可读取所选Offer；个人主页从用户选择的资料生成；社区内容由用户选择发布；真人辅导围绕指定材料或岗位成果开展 | 纳入整体产品能力；私有资料不因存在发布或辅导功能而自动对外共享 |
| 未来插件市场 | 更多外部服务、专业内容和工具按需启用，沿用产品已有能力与连接体系 | 与官方直接连接共用连接能力，继续遵守资料访问和岗位隔离规则 |

### 已确认的三层整合方式

| 层次 | 承担什么 |
|---|---|
| 产品内置能力 | 简历、练习、岗位进程、Offer与复盘 |
| 官方直接连接 | Gmail、Outlook等高频外部服务，用户直接授权连接；不要求先安装市场插件 |
| 未来插件市场 | 更多服务、专业内容和工具，用户按需启用 |

插件市场沿用能力与连接体系，同一外部连接不为内置入口和市场入口重复建设；启用插件不默认授予全部岗位资料访问。具体接口实现与供应商条件仍以技术验证为准。

### 准备内容组织的入口与触发

| 场景 | 用户触发方式 | 内容与归属 |
|---|---|---|
| 自由练习 | 主动请求整理某职业或主题的准备内容 | 根据目标与相关个人资料组织主题，选择后进入自由练习 |
| 岗位准备 | 在个人练习场选择岗位，或从岗位工作台进入后使用“帮我准备” | 按当前岗位JD、简历及已知考核要求整理内容，选择后进入该岗位练习 |
| 复盘后继续准备 | 在复盘中选择针对薄弱项继续练习 | 整理后续练习内容，继续归属当前岗位 |

内容可包括基础知识、岗位知识、个人经历讲述和针对性练习，复用已有职业内容与资料。有岗位工作台即可组织岗位准备，无需等待邀请。用户可跳过清单直接练习；新邀请到来不自动重写已有准备内容。

用户另提及“canvas”的简历修改能力。具体产品名称仍在澄清；本轮暂按Canva查阅官方技术资料，不将这一假设写成已选定的供应商。

本轮研究事实见[竞品功能与外部接入核验](research/2026-09-14-capabilities-and-integrations.md)。研究结论不自动替代用户对具体方案的决定。

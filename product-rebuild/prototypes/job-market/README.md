## 浏览器连接的技术边界

本次链路中，读取官网由 **Codex 已授权的 Chrome 浏览器能力**完成；Career OS 普通网页不能自行读取另一个跨域标签页。演示已完成“浏览器读取结果 → 本地接收 → 创建工作台”的后半段，但没有将 Codex 的能力内置进本产品。

`#capture=` 仅用于本地公开 JD 的演示交接。字段检查不等于认证或可信来源证明；生产实现应使用经过认证的连接通道和可核验的采集记录，不通过地址传递个人资料。网页正文仅作为数据保留，不执行其中的脚本或指令。

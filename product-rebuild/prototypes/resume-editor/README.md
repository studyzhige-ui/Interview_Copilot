# Career OS 简历编辑器

这是可实际操作的本地编辑器，与现有个人资料原型连接。不是旧产品后端的生产模块。

运行 `server.py`，打开 `http://127.0.0.1:8790/`，在个人资料点击“制作简历”。直接访问 `/editor/index.html` 可继续编辑上次的版本。

支持富文本、经历条目、模块增删与排序、三种模板、字体与间距、照片、实时分页、长段落拆页、手动模块分页、撤销重做、本机保存、独立版本、历史恢复、PDF、DOCX、PNG、TXT 与 JSON 备份。PDF 从浏览器实际布局导出，中文字体嵌入，文字可选择；DOCX 为可编辑段落和格式，Word/WPS 的排版可能变化。

数据保存在此目录 `local-data/`，不提交到版本库。浏览器另留当前草稿；文件服务仅绑定回环地址。Quill 2.0.3 来自官方发布包，保留源码许可声明。微软雅黑和宋体由本机 Windows 字体生成供本机使用，字体文件不提交。

当前边界：真实 Agent 未连接；现有 PDF/DOCX 导入仅从个人资料的解析结果生成新文档，不能无损恢复任意外部版式；不包含 Canva 的任意图层绘制；不是云端同步和多用户产品。Today 的独立设计未改动。

依赖：Python 3，python-docx、reportlab、fonttools、beautifulsoup4、pymupdf、Pillow。入口沿用此会话现有个人资料导出路径；换机器时需调整 server.py 的 PROFILE 路径。

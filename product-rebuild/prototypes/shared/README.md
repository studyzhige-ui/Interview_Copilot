`index.html` 和 `host.js` 提供常驻应用外壳，`shell.js` 统一生成主导航。一级入口只切换内容区，侧栏不重建；同源内容页缓存于 iframe，保留表单、对话和滚动状态，岗位市场与我的投递复用同一内容实例。使用哈希路由支持前进、后退及直接链接；消息验证来源窗口与 origin。直接打开旧页面地址会进入统一外壳。未设计模块标记待开放。工作台仍从岗位卡进入。简历编辑器返回个人资料；明确制作新简历时消费新资料快照。

Today 使用视口内的三行网格，上下两行等高，中间自适应；面板内的长内容独立滚动。窄屏改成内容区内的单列滚动，外层和侧栏不滚动。

岗位市场支持多选公司协作上下文：星芒点亮表示已选，再点移除，与收藏独立。协作栏列出公司标签，可单独移除或清空；演示公司和岗位结果均限定于已选公司。

`design-system.css` 在页面原有样式之后加载。统一桌面侧栏 208px，正文水平边距 34px，顶部 44px，页头 69px。字号使用 34px 页面标题、20px 模块标题、18px 岗位标题、14px 正文、12px 辅助信息，导航 15px。共用样式不覆盖简历纸张内部的字号和用户排版设置。Today 中央问候语保留独立视觉层级。

后续页面应复用这两个文件与已有字号变量。页面特有的内容布局留在各自目录，不复制主导航或另建一套页头。修改公共样式后检查四个主页面及编辑器返回入口。

所有页面由 resume-editor/server.py 提供服务，Today 和个人资料已直接使用项目内文件，不再依赖临时预览目录。同一 localhost 端口下的浏览器存储键不变，未迁移或清空用户记录。

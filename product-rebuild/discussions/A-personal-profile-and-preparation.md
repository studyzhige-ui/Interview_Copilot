# A阶段：个人资料与求职意向、个人练习场

> 状态：产品定义已确认，A阶段讨论完成。更新：2026-09-13。
> 本文是A阶段的当前产品定义，替代原旅程J01—J04及此前A阶段讨论稿。完成的是产品定义，不表示页面或功能已经实现。

## 1. 阶段范围与工作

A阶段帮助用户维护求职资料，并持续准备面试。服务于各职业领域，当前求职环境以中国大陆校招、实习和早期社招为主。用户可以维护资料、开展练习和投递并行进行，不要求先填完档案或完成学习计划。

| 阶段 | 用户要完成的工作 | 产品应保存的结果与规则 | Agent可以承担的工作 |
|---|---|---|---|
| A1 个人资料与求职意向 | 自主选择填写、导入和编辑个人信息、求职意向、经历与能力资料；按需润色 | 保存个人资料与附件；UI和Agent使用同源能力维护同一份资料；冲突修正由用户决定 | 调用导入、读取和编辑能力；基于已有资料润色；按需检查；交互中发现档案冲突时轻量提醒 |
| A2 个人练习场 | 选择专业知识、技能、项目、实习经历或自定主题，进行学习与问答练习 | 保存练习记录、用户选择保留的笔记及需要继续练习的问题；准备成果与个人资料分别保存 | 结合精选职业内容、个人资料和用户目标组织练习，提供讲解、提问、追问与反馈，支持下次继续 |

招聘流程研究以大公司招聘官网为依据。高校职业发展服务不用于推导产品职责；学校事务、课程、论文及其与求职的时间权衡由用户自行安排。教育经历仍属于个人资料。

## 2. 个人资料与求职意向

以[BOSS在线简历页面](https://www.zhipin.com/web/geek/resume)的资料内容和基础功能为基础，重新设计排版与页面呈现。用户自己决定填写哪些板块和内容，允许空缺并随时补充，不以资料完整度限制使用。

### 页面内容与基础功能

| 部分 | 内容与操作 |
|---|---|
| 个人信息 | 基本信息、求职状态及到岗信息 |
| 个人优势 | 用户对自身优势的介绍 |
| 求职意向 | 期望职位、行业、城市、薪资等，支持多个意向 |
| 经历与能力 | 工作/实习经历、项目经历、教育经历、资格证书、社团/组织经历、志愿者经历、专业技能 |
| 板块导航 | 通过目录定位相应资料板块 |
| 简历与附件 | 维护在线资料和附件，提供导入已有简历、预览及导出为附件简历的操作 |
| 完善辅助 | 提供AI润色、按需检查及上传简历的ATS检查与评分工具，辅助用户优化简历；用户决定是否采用建议 |

个人资料是用户持续维护的结构化信息；各模块使用适合内容的独立字段，如姓名、联系方式、职位、公司、角色、日期等，不将整个模块合成一个大文本框。个人优势、工作内容、项目描述与业绩等表达内容使用文本编辑区，并在相应输入区提供AI润色。

附件是保存和使用的原文件。统一通过“上传简历”保留附件并提供简历解析，不另设用于粘贴TXT的“导入资料”入口。解析后询问用户是否根据简历更新档案；用户可以只保留附件，也可以查看解析结果与当前档案的差异、修正内容并选择更新。未选择或未解析出的字段不覆盖、不清空原资料。导出将用户选择的资料生成独立简历文件；BOSS的招聘方可见性、屏蔽公司等平台发布设置不纳入本阶段的资料维护功能。

### 能力同源与AI辅助

| 能力 | 产品行为 |
|---|---|
| 导入、读取、编辑 | 属于产品底层能力。用户通过UI直接操作，或让Agent调用同一套能力，结果落在同一份资料中 |
| AI润色 | 在资料输入框下提供AI润色选项；用户填写后主动使用，也可以结合已有个人资料进行个性化优化 |
| 按需检查 | 根据用户需要读取正在维护的资料并检查；不强制补全，不持续扫描 |
| ATS简历工具 | 用户上传简历后可以使用检查与评分辅助优化；同一类工具也用于具体岗位进程中的简历优化 |
| 冲突提醒 | 用户与AI交互时，如果本次读取了档案且发现交互内容与档案冲突，AI给出小提醒，询问是否修正。由用户决定是否修改，不自动覆盖，也不默认本次说法一定正确 |

## 3. 个人练习场

个人练习场统一承接自由练习、岗位专项准备和复盘。通用的自由练习随时可用，不依赖岗位或招聘进程。岗位工作台一经创建，即可从工作台或个人练习场选择该岗位进行准备，不受投递、邀请或后续阶段限制。两个入口打开相同的练习或复盘界面与记录。完整关系见[C阶段第1—5节](C-selection-and-interview.md)。

### 页面组织

| 页面 | 内容与用途 |
|---|---|
| 练习入口页 | 继续已有练习；自由选择主题、经历或职业内容；从岗位列表进入专项准备；按考核场次查看和开展复盘 |
| 单次练习页 | 围绕选定内容进行问答、讲解、模拟面试和笔记整理；显示自由练习或当前公司、岗位及已知轮次；学习与练习可随时切换 |
| 复盘页 | 关联具体岗位及考核场次，整理记录、反馈与改进行动；从岗位工作台进入时打开同一份复盘 |

### 使用流程

| 环节 | 用户与产品的行为 |
|---|---|
| 选择内容 | 选择专业知识与技能、一段项目或实习经历、职业内容库中的主题，或直接输入想练的内容；AI按需读取相关资料 |
| 学习与梳理 | AI讲解专业知识、梳理项目思路或协助整理经历的讲述方式 |
| 问答练习 | AI提问，用户回答，AI继续追问并提供反馈；遇到不理解的内容可转为讲解，再继续练习 |
| 保留与继续 | 保存本次记录、用户选择保留的笔记和需要继续练习的问题；下次从这些成果继续 |

### 准备内容与成果

| 准备内容 | 要帮助用户完成的工作 |
|---|---|
| 专业知识与技能 | 理解和运用目标职业相关知识。技术栈是其中一种，不作为全体用户的默认内容 |
| 项目经历 | 讲清背景、个人职责、方案选择、难点及结果，并应对追问 |
| 实习与工作经历 | 讲清实际工作、个人贡献、问题处理及收获 |
| 基础能力 | 练习目标岗位所需的问题分析、沟通和面试表达等能力 |

练习成果包括本次主题与问答记录、讲解和反馈、用户保留的笔记、需要继续练习的问题。准备成果与个人资料分别保存；一次回答表现不直接改写档案。发现资料事实冲突时，沿用个人资料中的轻量提醒机制。

练什么与为哪个岗位练是两个维度。基础知识同样可用于岗位专项准备，不建立重复内容库。自由练习记录不绑定岗位；岗位专项记录归属对应岗位，从两个入口访问同一份成果。共享职业知识与个人资料，不自动共享不同岗位的JD、简历、练习对话和复盘。

## 4. 职业内容供给

用户可在练习前或两次练习之间主动让Agent整理准备内容，再选择主题进入已有练习界面；可删除、补充或跳过建议直接练习。自由练习依据目标与个人资料，岗位准备另按当前岗位范围读取JD等材料，复盘后的后续练习继续归属该岗位。不强制生成或完成学习计划，不因新邀请自动重写已有准备内容。完整入口与触发方式见[功能全景中的准备内容组织](../05-product-capability-map.md#准备内容组织的入口与触发)。

采用“常用职业精选内容库＋个人资料补充＋按需生成练习”。服务范围面向各职业，精选内容逐步积累，不要求先建齐所有职业的知识库才能使用。

| 内容来源 | 保存和提供的内容 | 用途 |
|---|---|---|
| 通用内容 | 自我介绍、经历讲述、沟通协作、问题分析等跨职业主题 | 支持各职业共用的基础练习 |
| 常用职业精选内容库 | 职业知识主题、典型问题、工作情境、参考解析与评价要点 | 支持专业讲解、出题、追问和有依据的反馈 |
| 个人资料补充 | 用户已有的经历、技能、作品及资料 | 将练习与用户实际背景结合；岗位准备另按当前岗位范围读取JD等专属信息 |
| 按需生成 | 根据用户目标和可用内容组织本次问题、情境与追问 | 满足个性化主题及尚未被精选库覆盖的练习需求 |

内容采用统一体系，按职业、能力和经验层级等分类复用。维护重点包括知识依据和评价要点：有明确答案的问题检查正确性，开放问题依据分析过程、论据和情境给出反馈，不以命中关键词代替评价。

精选内容使用允许使用的专业资料，保留来源与更新信息，并进行专业审核和持续更新。生成内容与已审核内容分开标识；未覆盖领域可根据用户提供的资料练习，但不能把模型生成的答案当成已经核验的专业标准。

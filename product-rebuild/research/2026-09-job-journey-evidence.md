# 求职旅程研究：来源与竞品核验记录

> 核验日期：2026-09-10 至 2026-09-11。主场景：中国大陆校招、实习、早期社招。  
> 本记录支持 [求职旅程研究稿](../00-career-os-reframing.md)。不将营销宣称、候选人自述或研究推论混称为已验证事实。

## 1. 证据等级与使用方法

- **招聘方公开规则**：支持某企业、某招聘项目或批次存在某规则，不推广为所有企业的统一流程。
- **高校与公共就业服务**：支持候选人确实面对某项准备或办理工作；学校流程以具体学校通知为准。
- **候选人自述**：用于发现真实处境与异常路径；身份、经历和结果未经独立核实，不代表发生率。
- **竞品公开能力**：官网或帮助页明确描述的功能；不代表已实测质量、已验证跨模块数据流或内部 Agent 架构。
- **设计推论**：从以上证据推导的产品结果、规则及 Agent 工作，仍待产品讨论和真实使用验证。

本轮未进行受访者访谈、真实申请跟踪、付费产品试用，也未登录竞品上传用户资料。以下完成的是公开资料核验，不称为全部产品功能验收。

研究发现：企业官网也存在旧页、搜索缓存和不同年份问答混杂。旅程中的“招聘规则”应带有公司、项目、地区、批次、来源与核验时间；信息不足时保留未知。收到具体邀请或招聘方澄清后，需要与泛化FAQ对照。

## 4. 竞品对旅程研究的实际贡献

| 工作 | 竞品补充的可观察形态 | 不能因此得出的结论 |
|---|---|---|
| 方向探索 | 偏好、方向建议、参考JD、周计划 | AI生成的方向已证明适合用户；参考JD表示市场有此职位 |
| 材料准备 | 按JD编辑、多版本、故事库、预览与导出 | 简历评分代表招聘方评价；分数提升意味着能通过筛选 |
| 机会管理 | 招聘日历、收藏、投递与日程跟踪 | 已具备中国企业各批次的完整投递规则 |
| 面试准备 | 岗位上下文、公司面经、模拟追问、专项练习 | 题库能保证预测本轮题目；题库宣传数量等于可靠覆盖 |
| 真实面试 | 实时音频、提示、翻译、屏幕理解等不同形态 | 这些形态在每场招聘考核中均被允许；我们已决定纳入 |
| 复盘 | 记录、报告、下一轮练习、跨场材料使用 | 观察可靠、改善可归因、长期记忆已正确更新 |

## 5. 仍需继续验证的内容

本轮可以支持一份有依据的旅程初稿，不能宣称已穷尽真实求职。样本仍偏向科技企业与技术岗位。

- 中小企业、非技术早期岗位、国企银行的实际分支尚缺足够一手材料。
- 候选人访谈仍缺：建议分别复原校招、日常实习、转正实习、在职社招各一段完整时间线，尤其记录遗漏、重复劳动和放弃原因。
- 需要真实但经用户选择与脱敏的材料样本：JD、投递回执、改期通知、测评邀请、Offer清单；本轮不要求上传，也未采集。
- 产品实际能力深度，需要在选择重点对标任务后完成操作验证；不能把本轮公开核验说成全部竞品完整实测。
- 对具体资格、签约、体检、背调、辞职、档案与户籍问题，应以相关当事人的现行文件和通知为准；本稿仅定义需要承接的工作，不给出统一法律或医疗结论。

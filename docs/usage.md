# 功能使用帮助

## 账号与模型

进入应用后注册或登录，完成邮件验证。在设置中选择回答模型，并填写所需的个人 API Key。切换模型前确认对应服务可用、账户额度充足。

自部署环境还需由部署者填写内部模型、检索和语音服务配置；个人 API Key 不会替代这些配置。默认本地认证未配置 SMTP 时，验证码会出现在 API 日志中；公开部署应配置真实邮件服务。

## 简历、JD 与知识资料

上传资料后等待处理状态完成，再进行检索或提问。处理失败时查看失败提示，并在修正服务配置后重试。修改、删除资料后，后续检索以当前仍可访问的资料为准。

回答中的引用用于定位来源；涉及求职事实、公司信息和简历经历时，提交或发送前自行核对。

## 岗位与求职事项

在岗位工作区添加公司、岗位和进展，记录下一步行动。导入文件后先核对字段与日期，再确认写入。使用页面提供的导出功能保存需要分享或备份的内容。

## 对话助手

说明任务、使用哪些资料、期望的输出及完成条件。任务运行时可查看工具记录；不需要继续时使用取消。发生中断后回到原会话查看状态，避免重复提交相同任务。

涉及外部工具时，在设置或能力页面连接所需服务。工具可用性取决于部署配置、账号授权和当前权限。

## 模拟面试

选择相关简历、岗位和面试设置，开始后按问题回答。结束后查看反馈和待改进项。反馈用于练习，不代表真实招聘结论。

## 录音与复盘

使用前准备好语音模型、运行转写服务，并授予麦克风权限。录音保存后等待转写；长录音和 CPU 模式可能需要较长时间。刷新页面后先查看原任务状态，确认失败后再重试。

复盘时核对说话人、转写和问答对应关系，必要时修订后重新查看结果。保留原录音，避免把自动转写错误当成真实回答。

## 记忆设置

自动记忆形成默认关闭，需部署者启用后，用户再在个性化设置中选择是否贡献。已有有效记忆的召回受账号和会话设置控制。没有可复用信息的对话不一定形成记忆。

修改或删除不准确的记忆后，再发起新问题检查效果；重要个人信息仍应在当前任务中明确说明。

## 资料和数据安全

个人 API Key 在设置中管理；不要放进聊天内容、截图或公开文档。分享导出文件前检查个人信息。日常停止容器会保留数据；备份和升级操作见 [Community 部署帮助](deployment/community.md)。

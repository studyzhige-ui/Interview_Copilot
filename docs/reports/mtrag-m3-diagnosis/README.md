`Virtualization` 被改写为Red Hat OpenShift virtualization；标注指向通用IBM Cloud Virtualization文档。
前文确实讨论OpenShift，因此不能仅凭分数下降就断言改写一定不合理。原问题与历史解释可能需要共同保留。
`Restrictions to immigration` 被加上same-sex couples也存在类似话题边界歧义。

### 需要标注复核：不同页面可能包含相同证据

片段ID级评测可能将语义相近的未标注证据计零。未修改qrels，也未把未标注结果直接改判正确。

## 下一步的三个定向对照

1. 保留两路召回并集，直接重排：隔离融合截断造成的证据损失。
2. 在此基础上加入原问题召回：检验原问题是否补回改写遗漏的证据。
3. 在相同候选上加入原问题重排，按固定权重融合两次排名：检验重排仅依赖改写是否继续压低原问题证据。

模型固定M3；输入长度保持512；复用现有改写，不调用生成模型或修改改写缓存。
先比较659道调参题，冻结唯一方案后比较450道内部验证题。验证集已经在此前轮次使用，不宣称全新独立盲测。
若验证质量门槛未通过，保留原基线，不将候选覆盖提升冒充最终检索质量提升。

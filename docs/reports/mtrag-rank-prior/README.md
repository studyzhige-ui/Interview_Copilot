# 原检索排名与 M3 重排融合实验

固定v1改写、两个M3模型、原融合50候选、512输入。假设：重排完全覆盖原检索排序时，会丢掉有价值的召回排名信号。

实验只将原融合排名以10%或25%权重加入最终排名，重排占90%或75%，两者以常数60做加权RRF。没有加入未消解的原问题，也没有新增候选。

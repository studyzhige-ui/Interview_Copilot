# 发布修复实施账本（2026-09-23）

结论：本轮已修复多项安全、并发、持久状态和用户恢复路径问题，但 **尚未达到发布标准**。RAG 真实校准质量仍未通过；完整浏览器用户旅程、生产容量及部分资源生命周期边界仍需验收。不能将单元测试通过解释为全部缺陷已消除。

范围依据：[手册审查报告](../reports/handbook-audit-2026-09-23/README.md)及当前代码实际输入、事务与执行路径。工作区原有 pgvector 和记忆重构得到保留，没有回退用户的既有修改。本轮未部署、未提交 Git、未修改生产数据库。独立 Docker 数据库、Redis、对象存储用于验证。

## 代码清理

- 删除无真实调用者的 LLM 工厂入口和聊天伪兼容分支；保留仍被结构化面试分析调用的 LlamaIndex 适配层。
- 移除取消的 Redis request/wait 协议、旧 mock 和删除入口里的重复通知；取消统一服从持久 Turn。
- 移除无业务读取者的 Celery result backend 依赖；任务发布失败保留明确的持久修复边界。
- 对齐过期提示词和历史迁移测试；历史迁移按当时 schema 创建数据，避免拿新 ORM 伪装旧表。
- 0052 删除 memory_extraction_cursor 和 last_dreamed_at 等已退出模型的游标列。
- Ruff 覆盖 backend、alembic、evaluation、scripts。保留既有 pgvector 替换 Milvus 工作，不把先前修改冒充本轮新增成果。

## RAG 发布阻塞的实际证据

真实 BGE-M3、BGE reranker、CUDA、25 份公开语料和 PostgreSQL 索引，执行 133 条 calibration 样本（115 可答、18 不可答）。规划器快照包含 421 条；保留的 288 条检索测试样本没有用于调参，校准失败后未执行正式保留集验收。

| 指标 | 结果 |
| --- | ---: |
| 候选金标准证据命中 | 99.13% |
| 原始重排 Top-3 命中 | 95.65% |
| 最终证据 Top-3 命中 | 88.70% |
| 最终查询 precision | 91.07% |
| 最终 evidence-group recall | 87.97% |
| 最终证据 precision | 64.20% |
| 不可答问题误召回 | 0 / 18 |
| 检索 p95（不含独立 planner 耗时） | 1256.34ms |
| 跨租户泄漏 | 0 |

**已确认定位**：大多数目标证据进入候选集，但重排与最终筛选未同时满足正确性和覆盖率要求；单纯增加向量召回数量不是已被证据支持的根因修复。现有阈值校准没有找到满足全部规则的组合。部署阈值与发布门槛未降低。

**实验否定的简单方案**：单意图改用原始问题，最终命中仍 88.70%；去掉 document/section 前缀，降至 78.26%；原问题与双语查询的重排分数均值，降至 87.83%。均仅用于 calibration 诊断，未合入生产算法。

**待验证假设**：不同格式的结构性证据分块边界、章节元数据噪声、相关但不回答问题的高分段落，使交叉编码器分数不足以判定证据充分性。需检查原文→分块→完整 reranker 输入→选中证据链路，再设计证据选择契约。不能将假设写成已修复根因或针对样本 ID 硬编码。

质量实验采用本机 Python 3.11 CUDA 环境，部分 ML 依赖版本与锁定 Python 3.13 容器不同，版本保留在证据中。结果用于暴露问题，不能作为最终发布认证。

## 验证材料及适用边界

最终测试结果和脱敏摘要：[发布验证目录](../reports/release-hardening-2026-09-23/README.md)。原始实验脚本/日志保留于忽略的 data/runtime/，不将临时密钥或完整运行目录加入版本控制。

## 升级与发布顺序

1. 备份 PG 和对象存储并验证恢复；停 API 写入和全部 worker，避免新旧进程混跑。
2. 确认 PG 有项目要求的 pgvector 扩展，执行 alembic upgrade head、alembic check。最新 revision 是 0052，类型转换可能持有表锁，须按实际数据量估计维护窗口。
3. 0052 废弃游标降级只重建空列。需要精确回退历史状态时使用事前备份。
4. 认证迁移 0049 提升现有账户 token_version，**所有已有会话需重新登录一次**，避免丢失旧 Redis 撤销事实。
5. 构建匹配前后端和新依赖后启动；验证健康、登录、刷新、流式回复、取消、附件、任务恢复及备份恢复。
6. RAG 全部门槛、保留集、真实浏览器核心旅程和目标负载压测通过前，不批准正式发布。
